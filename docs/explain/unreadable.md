# unreadable: The module had no text the model could be sent

## What it means

When Vettalon prepared the prompt for this module, no file produced readable text. No model review took place. The module counts as failed in the coverage summary, and it is not clean.

## Why you see it

The files may be unreadable, outside the repository, or all excluded by the prompt size limit. The file records show the individual reasons.

## What to do

Open the module's file records. Fix permissions or paths, or review the module by hand, then rescan.
